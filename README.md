# Test Engineer Track

A training platform that turns non-technical test specialists into test engineers:
ISTQB prep + AI curriculum, with quizzes, exams, and spaced-repetition flashcards,
and cohort tracking.

**Status:** early development (M1 walking skeleton). See `docs/` for the spec and plan.

## Development

```bash
pnpm install
pnpm --filter tet-core test   # run core package tests
```
