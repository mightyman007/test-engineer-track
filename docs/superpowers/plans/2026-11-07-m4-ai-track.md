> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the AI for Test Engineers track — 8 modules from zero knowledge to AV-specific understanding (one-stage vs two-stage detection, testing AI systems) — with quizzes, flashcards, two AI mock exams, readiness wiring, and the ledgered M4 hooks (term-link liveness checker, PINNED_DRAWS re-point, content consistency pass).

**Architecture:** No engine changes. The AI track is a second manifest track (`ai-fundamentals`, order 2) riding the existing platform: per-module content dirs (lessons/TOML banks/decks), two exam definitions using **count-only groups without K cells** (AI questions carry no `klevel` — the legacy assembly path covers them; `blueprintExact` omitted since AI has no official blueprint), readiness wiring via `readiness.examIds`. One small platform addition: the in-browser neural-network toy demo for module A3, and the term-link liveness checker extension.

**Tech Stack:** unchanged. The toy demo is a self-contained React component (~100 lines, no ML library — a perceptron trained by hand-rolled gradient descent on a tiny dataset, canvas-rendered).

**Spec:** `docs/superpowers/specs/2026-11-07-test-engineer-track-design.md` (§4 Track 2: 8 modules with the exit criteria; §7 exam schema; AI exams 30 Q / 45 min / 70%).

## Global Constraints

- TypeScript `strict: true`; `noUncheckedIndexedAccess: true`; NO new dependencies (the toy demo is hand-rolled canvas + requestAnimationFrame — no TF.js).
- All content original; external links must be REAL and live (the term-link checker from Task 1 enforces corpus-wide).
- Every lesson: ≥1 inline diagram + ≥1 frontmatter video; `##` TTS sections; term links on first use; plain English for non-technical readers; house SVG spec (≤40 lines, 800×450 viewBox, #1a1a2e on light, system font, newline-terminated, no text overlaps).
- AI question ids: `ai-q-0001+`; cards `ai-fc-0001+`; lesson ids `ai-mN-<slug>`; module ids `ai-m1..ai-m8`; tags `ai1..ai8` (chapter-style tags keep the exam-group mechanism).
- **No klevel on AI questions** (no official K classification exists) — exam groups use counts only; `blueprintExact` omitted; global `klevels` omitted.
- AI exams: 2 × 30 Q, 45 min, pass 70%; groups = the 8 module tags with counts summing 30 (e.g. 4/4/4/4/4/4/3/3); readiness: passPct 70, readyPct 78 (spec §5).
- Answer-position balance: ~25% per position, non-cyclic permutation; post-reorder re-read (standing M2 rule).
- Quiz/exam/flashcard engines unchanged; per-module quiz draws 12 (existing behavior).
- The M2 ISTQB surfaces are untouched except the manifest gaining a second track and the consistency-pass edits Task 8 names.
